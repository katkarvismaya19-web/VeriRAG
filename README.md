# VeriRAG

**Evidence-Grounded Enterprise Knowledge & Decision Intelligence Platform**

VeriRAG is a production-oriented Retrieval-Augmented Generation (RAG) platform designed to answer questions from enterprise knowledge while providing verifiable evidence and transparent retrieval quality.

## Core Capabilities

- Document ingestion and processing
- Semantic and hierarchical chunking
- Vector and keyword retrieval
- Hybrid search
- Reranking
- Query rewriting
- Multi-document and multi-hop reasoning
- Evidence-grounded answers
- Citation generation
- Insufficient-evidence detection
- Contradiction and document-version awareness
- Role-based access control
- RAG evaluation and benchmarking
- Feedback and analytics
- Observability and audit logging

## Architecture

- **Frontend:** Next.js, TypeScript, Tailwind CSS
- **Backend:** Python, FastAPI
- **Database:** PostgreSQL + pgvector
- **Cache / Workers:** Redis
- **RAG:** Custom retrieval and orchestration pipeline
- **Infrastructure:** Docker and CI/CD

## Project Status

🚧 Currently under active development.

## Goals

The goal is to build a production-quality RAG system that is measurable, explainable, secure, and deployable rather than a basic document chatbot.
